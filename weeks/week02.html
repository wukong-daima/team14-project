파운데이션 모델 아키텍처

현대 LLM의 '사실상 표준' 부품(서브워드 토크나이저 · GQA/MLA/DSA · RoPE · Pre-Norm · MoE), 학습 레시피(SFT → DPO/GRPO → On-Policy Distillation), 추론 가속(KV 캐시 · Speculative Decoding · MTP), 그리고 "AR과 Diffusion은 정말 다른가"까지 한 번에 훑는 주차입니다. 공통 주제는 하나, 긴 문맥을 싸게 처리하기.

요즘 AI 언어 모델은 레고처럼 표준 부품으로 조립됩니다. 이번 주는 그 부품들이 뭔지, 왜 그 부품을 고르는지, 그리고 AI를 빠르게 만드는 요령을 배웁니다. 핵심은 "긴 글을 읽을 때 메모리를 아끼는 법"이에요.

2. 핵심 개념

CONCEPT 01 · p.4–9

서브워드 토크나이저 (Subword Tokenizer)

토크나이저는 텍스트를 정수 ID 시퀀스로 바꾸는 장치입니다. 단어 단위는 어휘가 폭발하고 처음 보는 단어(OOV)를 [UNK]로 잃습니다. 글자 단위는 OOV가 없지만 시퀀스가 너무 길어져 생성이 느리고 글자 하나의 표현을 배우기 어렵습니다. 서브워드는 자주 쓰는 단어는 통째로(dog), 희귀 단어는 의미 단위로(token + ##ization) 쪼개는 절충안이며, BPE · WordPiece · Unigram · SentencePiece가 대표 알고리즘입니다. 파이프라인은 Raw text → Tokenizer → Input IDs → Model → Logits → Post-processing 이고, 마지막 층 직전 벡터를 penultimate(특징 추출용), softmax 직전 벡터를 logit이라 부릅니다.

문장을 레고 블록으로 쪼개는 방법이에요. 단어 하나를 블록 하나로 하면 블록 종류가 너무 많고, 처음 보는 단어는 블록이 없어요. 글자 하나를 블록 하나로 하면 종류는 적지만 블록을 너무 많이 꽂아야 해요. 서브워드는 "자주 쓰는 덩어리"를 블록으로 삼는 중간 방법입니다.

CONCEPT 02 · p.17, 22–27

MHA → MQA → GQA: KV 캐시와 성능의 줄다리기

MHA는 헤드 H개가 각자 Q, K, V를 가지므로 추론 시 KV 캐시가 H에 비례합니다. MQA(Shazeer 2019)는 모든 헤드가 K, V 하나를 공유해 캐시가 1/H로 줄지만 품질이 떨어집니다. GQA(Ainslie 2023)는 쿼리 헤드를 g개 그룹으로 묶고 그룹마다 K/V 하나를 둡니다. GQA-1 = MQA, GQA-H = MHA이고 논문에서는 GQA-8이 좋은 균형을 보였습니다. 기존 MHA 체크포인트를 GQA로 바꿀 때는 그룹 내 K/V 투영 행렬을 평균(mean pooling)한 뒤 짧게 추가 학습합니다.

KV 캐시 크기: 2 × layers × n_kv × d_head × L × bytes (MHA n_kv=H, GQA-g n_kv=g, MQA n_kv=1)

교실에 학생(쿼리) 32명이 있고 각자 교과서(K/V)를 한 권씩 가지면 사물함이 꽉 차요(MHA). 교과서 한 권을 반 전체가 돌려보면 사물함은 비지만 줄 서느라 공부가 안 돼요(MQA). 4명당 한 권씩 모둠으로 나누면 적당해요(GQA). 요즘 AI는 거의 다 이 모둠 방식을 써요.

CONCEPT 03 · p.28

MLA (Multi-head Latent Attention, DeepSeek-V2)

K와 V를 그대로 저장하는 대신 저차원 잠재 벡터 c로 공동 압축(low-rank joint compression)해 캐시하고, 어텐션을 계산할 때 up-projection으로 K, V를 복원합니다. 캐시 크기가 헤드 수가 아니라 잠재 차원 d_c로 정해지므로 GQA보다 더 작게 만들면서 MHA급 품질을 노립니다. down-projection과 up-projection 두 파라미터로 구성됩니다. 논문 수치(DeepSeek-V2에서 MLA 캐시 ≈ GQA 2.25그룹 수준)는 슬라이드에 없고 원 논문에 있습니다.

교과서를 통째로 사물함에 넣는 대신 "요약 노트(c)"만 넣어 두고, 필요할 때 노트를 보고 교과서 내용을 다시 펼치는 거예요. 노트가 얇으니 사물함이 훨씬 덜 차요.

CONCEPT 04 · p.29–33

DeepSeek Sparse Attention (DSA)과 블록 단위 개선

요약본의 "DSA (DeepSpeed Sparse Attention)"는 DeepSeek Sparse Attention입니다. Microsoft의 DeepSpeed 라이브러리와 무관하며 출처는 DeepSeek-V3.2 기술 보고서입니다 (p.32~33). 또 "QSA (Qwen-Next)"라는 명칭은 슬라이드에 없고, 원문은 "DeepSeek V4/V4.1 and Qwen QSA have improved DSA (block-level attention by key aggregation)"입니다.

어텐션은 RBF 커널로 볼 수 있어 softmax(QKᵀ)V ≈ φ(Q)φ(K)ᵀV처럼 근사할 수 있습니다(Implicit Kernel Attention). DSA는 두 단계입니다. (1) 가벼운 projection으로 쿼리와 키 사이의 index score를 계산해 top-K 키를 고른다. (2) 각 쿼리가 선택된 K개 키에만 어텐션한다. 복잡도는 O(L²) → O(LK). DeepSeek V4/V4.1과 Qwen QSA는 키를 블록으로 묶어 먼저 블록을 고르고 그 안에서 키를 고르는 식으로 DSA를 개선했습니다. 주의: DSA는 연산량을 줄이는 것이지, 모든 키의 KV는 여전히 캐시에 있어야 하므로 저장 메모리를 직접 줄이진 않습니다.

책 1,000쪽을 다 읽는 대신 목차(가벼운 index)로 관련 있어 보이는 20쪽만 고른 뒤 그 20쪽만 정독하는 거예요. 블록 방식은 "장(章)을 먼저 고르고 그 안에서 쪽을 고르는" 2단계예요. 단, 책 자체는 여전히 책장에 다 있어야 해요.

CONCEPT 05 · p.34–41

RoPE (Rotary Positional Embedding)

원 Transformer는 사인·코사인 절대 위치 벡터를 입력에 더했습니다(APE). 상대 위치 방식(Shaw 2018, SHAPE)은 쿼리와 키의 거리 정보를 어텐션에 직접 넣고 먼 거리는 clipping합니다(RPE). RoPE(Su et al.)는 위치 i에 의존하는 블록 대각 회전 행렬 R_i를 Q와 K에 곱합니다. 회전된 두 벡터의 내적은 자동으로 상대 위치 (i − j)에만 의존하므로, 절대 위치를 쓰면서 상대 위치 성질을 얻습니다. 현재 사실상 표준입니다.

시계 바늘이에요. 각 단어를 자기 자리 번호만큼 바늘처럼 돌려놓으면, 두 단어가 "얼마나 떨어져 있는지"는 두 바늘의 각도 차이로 바로 알 수 있어요.

CONCEPT 06 · p.42–52

Pre-Norm vs Post-Norm, 그리고 RMSNorm → DyT → BHyT

Post-Norm은 잔차 합 뒤에 정규화하므로 손실의 l번째 층 그래디언트가 야코비안의 곱으로 누적되어 깊어질수록 폭발·소실합니다. Pre-Norm은 서브층 앞에서 정규화하고 잔차 경로는 정규화를 거치지 않는 항등 경로라, 그래디언트가 덧셈 형태로 전파되어 안정적입니다(Wang 2019). RMSNorm은 평균 빼기(re-centering)를 생략하고 RMS로만 스케일해 연산을 줄이고, pRMSNorm은 앞 p% 원소로 RMS를 추정합니다. DyT는 LayerNorm의 S자 입출력을 y = γ·tanh(αx) + β로 대체해 통계 계산을 없애지만 실제로는 성능 저하가 관측됐고, BHyT(교수님 연구실, ICML 2026)는 블록당 분산을 한 번만 정확히 계산하고 나머지는 병렬 근사합니다(κ=10, p=0.99).

계단을 내려갈 때 매 층마다 바닥을 미리 평평하게 하고 내려가면(Pre-Norm) 안 넘어져요. 내려간 뒤에 평평하게 하면(Post-Norm) 층이 깊어질수록 휘청거려요. RMSNorm은 "평평하게 하기"를 더 싸게 하는 법이고, BHyT는 우리 교수님 연구실이 만든 더 싼 방법이에요.

CONCEPT 07 · p.53–54

MoE (Mixture of Experts)와 DeepSeek MoE

Dense FFN 하나를 여러 전문가 FFN으로 바꾸고, 게이트가 토큰마다 top-k 전문가만 고릅니다. 총 파라미터는 크지만 토큰당 활성 파라미터는 일부라서 같은 연산 예산으로 모델과 데이터 규모를 키울 수 있습니다. 토큰별로 독립적으로 라우팅됩니다. DeepSeek 변형은 shared expert(항상 활성)와 routed expert를 분리하고, 전문가 쏠림을 막는 보조 손실(auxiliary loss) 대신 라우팅 bias를 조절하는 auxiliary-loss-free 전략을 씁니다. 4주차에서 다룰 "추론 시와 학습 시 선택되는 전문가가 달라지는 문제"는 여기서 출발합니다.

병원이에요. 환자(토큰)가 오면 접수대(게이트)가 증상에 맞는 전문의 두 명만 배정해요. 의사가 100명 있어도 한 환자는 두 명만 만나니까 빠르죠. shared expert는 모든 환자가 거치는 "기본 진료"예요.

CONCEPT 08 · p.56–67

학습 파이프라인과 PEFT (Adapter · LoRA · Prefix)

Base I(pretrain) → Base II(continual pretrain) → SFT/IFT → PFT(선호 튜닝) → RFT(강화 튜닝) 순서이며 단계는 반복될 수 있습니다(Tulu 3, Nemotron Nano 2). 전체 가중치를 다시 학습하는 대신 PEFT를 씁니다. Adapter는 d→m→d 병목(파라미터 2md+d+m), LoRA는 h = W₀x + BAx로 ΔW=BA를 저랭크로 두고 B를 0으로 초기화하며 GPT-3 기준 학습 파라미터가 1/10,000입니다. "Unified View"(ICLR 2021)는 prefix tuning도 adapter의 변형으로 통합했고, in-context learning은 내부적으로 경사하강과 같다는 해석(von Oswald 2023)도 소개됐습니다.

이미 다 만들어진 로봇(사전학습 모델)에 작은 부품 몇 개(LoRA)만 끼워서 새 일을 가르치는 거예요. 로봇 전체를 다시 만들 필요가 없으니 싸고 빨라요.

CONCEPT 09 · p.68–89

선호 튜닝: RLHF(PPO) vs DPO vs GRPO

RLHF는 보상 모델을 먼저 학습하고 PPO로 정책을 최적화하는 online RL입니다. policy · reference · reward · value 네 모델과 반복 롤아웃이 필요해 무겁고, 보상 모델의 빈틈을 파고드는 reward hacking에 취약합니다. DPO는 보상 모델 없이 선호/비선호 쌍으로 정책을 직접 최적화하는 offline 방식이라 단순하고 안정적입니다. GRPO의 목적함수는 세 요소입니다. 확률비(새 정책/데이터 생성 정책) × 클리핑(PPO의 안정화 계승) × 그룹 상대 advantage(같은 프롬프트의 G개 응답끼리 정규화한 보상). 마지막 항이 PPO의 value 모델을 대체합니다. 한 그룹이 전부 실패(또는 전부 성공)하면 advantage가 0이라 학습 신호가 없습니다.

글짓기 대회예요. RLHF는 심사위원 로봇을 따로 만들어 점수를 매기게 해요(복잡). DPO는 "이 글이 저 글보다 좋다"는 쌍만 보고 바로 배워요. GRPO는 같은 주제로 8편 쓰게 한 뒤 "그중에서 잘 쓴 편"을 칭찬해요. 절대 점수표 없이 상대 평가만 하는 거예요.

CONCEPT 10 · p.90

On-Policy Distillation (OPD / OPSD)

요약본의 "OPD (On-policy Preference Distillation)"에서 "Preference"는 슬라이드에 없습니다. 제목은 On-Policy Distillation, 본문은 On-policy self-distillation(OPSD)입니다. "GRPO의 희소 보상 문제를 해결"은 구두 설명으로 보이며, 슬라이드의 근거는 "분포 불일치 감소 + dense 토큰 단위 감독"입니다 (p.90).

표준 증류는 교사가 미리 만든 고정 데이터로 학생을 가르칩니다(offline). On-policy distillation은 학생이 현재 정책으로 직접 생성한 궤적에 대해 교사(또는 더 강한 자기 버전)가 토큰 단위로 감독합니다. 학생이 실제 추론에서 방문하는 상태에서 배우므로 train–inference 분포 불일치가 줄고, 정답 여부만 보는 GRPO와 달리 매 토큰 dense supervision을 유지합니다. 대가는 강한 교사 모델에 대한 의존입니다.

선생님이 모범답안을 외우게 하는 대신, 학생이 직접 푼 풀이를 옆에서 한 줄 한 줄 봐주면서 고쳐주는 거예요. 내가 실제로 틀리는 자리에서 배우니까 훨씬 잘 늘어요.

CONCEPT 11 · p.91–96

추론 가속: KV 캐시 · Speculative Decoding · MTP

요약본의 "2~3배 향상, 평균 수락 4개" 수치는 슬라이드(p.92~94, 그림 전용)에 없습니다. 강의 중 구두 설명으로 표기합니다.

KV 캐시는 이전 토큰의 K, V를 저장해 재계산을 피하는 메모리↔연산 교환입니다. Speculative decoding은 작은 draft 모델이 여러 토큰 초안을 내고 큰 target 모델이 한 번의 forward로 병렬 검증합니다. 앞에서부터 일치하는 토큰까지만 수락하므로 출력 분포는 보존됩니다(이론상 무손실). MTP(Multi-Token Prediction)는 다음 1개가 아니라 여러 미래 토큰을 예측하도록 학습해(Independent → Sequential) 장기 의존 표현을 유도하고, 추론 시 MTP 모듈이 draft 역할을 해 speculative decoding과 결합됩니다(DeepSeek-V3).

받아쓰기예요. 빠른 후배(draft)가 다음 다섯 글자를 먼저 적으면, 느리지만 정확한 선배(target)가 한눈에 훑어서 맞는 데까지만 승인해요. MTP는 선배가 아예 "다음 몇 글자"를 한 번에 떠올리도록 훈련하는 거예요.

CONCEPT 12 · p.97–128

AR vs Diffusion: 정말 다른 패러다임인가

연속시간 masked diffusion은 random-order AR(N! 순열 중 하나)과 동치입니다. 병렬 생성은 diffusion 고유 속성이 아니라 "한 스텝에 몇 토큰을 unmask하느냐"라는 이산화 스케줄의 결과이고, 많이 뽑을수록 이산화 오차 ε_disc가 커져 slow-to-fast(코사인) 스케줄이 필요합니다. 연속 diffusion의 높은 품질도 log-SNR 기준 loss reweighting 덕이 크며 이는 MD4에도 적용됩니다. 따라서 진짜 질문은 "어떤 변수를, 어떤 순서로, 언제 생성하느냐"이고, 생성 순서를 학습(insertion 정책)하면 SMILES처럼 구조 토큰을 먼저 만드는 전략을 스스로 발견합니다. 현재 가장 실용적인 diffusion LM 용도는 AR의 speculative draft(DFlash, DSpark)입니다.

빈칸 채우기 문제지예요. 왼쪽부터 순서대로 채우면 AR, 아무 칸이나 골라 채우면 random-order AR, 여러 칸을 동시에 채우면 "병렬"이에요. Diffusion 언어 모델은 사실 "아무 칸이나 여러 개 동시에" 채우는 방식일 뿐, 마법이 아니에요.

3. 직접 해보기

🎮 KV 캐시 계산기 — MHA / GQA / MQA / MLA

슬라이더를 움직이면 헤드 연결도와 KV 캐시 메모리가 바뀝니다. "KV 그룹 수"를 1로 내리면 MQA, 헤드 수와 같게 올리면 MHA입니다.

공식: KV = 2 × layers × n_kv × d_head × L × bytes. MLA는 layers × d_c × L × bytes 로 근사했습니다(DeepSeek-V2의 분리된 RoPE 키 차원은 제외). GPU 장수는 KV 캐시만 기준이며 가중치는 포함하지 않습니다.

5. 시험 포인트

  • 토크나이저 3종의 장단점과 서브워드가 표준인 이유 (OOV ↔ 시퀀스 길이 트레이드오프)
  • MHA/MQA/GQA의 KV 캐시 크기 관계와 성능 순서. GQA-1 = MQA, GQA-H = MHA. MLA는 "저차원 잠재 c로 K,V 공동 압축"
  • DSA 2단계(index score로 top-K 선별 → 선택 키에만 어텐션), O(L²) → O(LK). 블록 단위 개선(V4/V4.1, Qwen QSA). 메모리가 아니라 연산량을 줄임
  • RoPE가 왜 APE + RPE인지 (회전 행렬 곱 → 내적이 상대 위치의 함수)
  • Pre-Norm이 안정적인 이유(그래디언트가 덧셈/항등 경로), RMSNorm이 싼 이유(re-centering 생략), DyT·BHyT의 위치
  • MoE의 연산 이점(총 파라미터 ≠ 활성 파라미터), DeepSeek의 shared/routed expert, auxiliary-loss-free
  • RLHF(online, 4개 모델, reward hacking) vs DPO(offline, 보상 모델 없음) vs GRPO(그룹 상대 advantage가 value 모델 대체, 확률비 · 클리핑)
  • Speculative decoding(무손실 병렬 검증) · MTP(여러 미래 토큰, draft로 활용) · "masked diffusion = random-order AR, 병렬성은 스케줄의 산물"

예상 문제

Q1. 쿼리 헤드 32, d_head 128, 레이어 32, 시퀀스 128K, FP16 모델에서 MHA 대비 GQA-8, MQA의 KV 캐시 비율을 쓰고 GQA-8의 용량(GB)을 계산하라.
비율 = 32 : 8 : 1. GQA-8은 MHA의 1/4, MQA는 1/32. GQA-8 = 2 × 32 × 8 × 128 × 131,072 × 2 bytes = 17,179,869,184 bytes ≈ 17.2 GB(10진) = 16.0 GiB(2진). MHA는 ≈ 68.7 GB = 64 GiB. 위 계산기는 GiB 단위로 표시합니다.
Q2. Post-Norm보다 Pre-Norm이 깊은 Transformer 학습에 안정적인 이유를 그래디언트 전파 관점에서 설명하라.
Pre-Norm은 잔차 경로가 정규화를 거치지 않는 항등 경로이므로 손실의 l층 그래디언트가 상위층 그래디언트의 합 형태로 전달된다. Post-Norm은 매 층 Norm을 통과하며 야코비안이 곱으로 누적되어 깊어질수록 폭발/소실한다.
Q3. GRPO 목적함수의 세 구성 요소와 각각이 PPO의 어떤 부분을 대체/계승하는지 설명하고, GRPO가 학습 불가능한 상황을 하나 제시하라.
(1) 확률비 π_new/π_old — PPO의 importance ratio 계승. (2) 클리핑 — 정책 급변 방지 계승. (3) 그룹 상대 advantage — 같은 프롬프트의 G개 응답 간 정규화 보상으로 PPO의 value/critic 모델을 대체. 한 프롬프트의 롤아웃이 전부 실패(또는 전부 성공)하면 advantage가 0이 되어 학습 신호가 없다.
Q4. DSA의 동작 2단계와 복잡도 변화를 쓰고, KV 캐시 메모리 자체를 줄이는지 논하라.
1) 가벼운 projection으로 쿼리–키 index score를 구해 top-K 키 선택, 2) 선택된 K개 키에만 어텐션. 연산 O(L²) → O(LK). 그러나 모든 키의 KV는 캐시에 있어야 하므로 연산량을 줄일 뿐 저장 메모리를 직접 줄이진 않는다. 메모리 축소는 GQA/MLA/슬라이딩 윈도우(3주차)의 역할이다.
Q5. "Diffusion 언어 모델은 병렬 생성이 가능해 AR보다 본질적으로 빠르다"는 주장을 강의 내용에 근거해 비판하라.
연속시간 masked diffusion은 random-order AR과 동치이므로 병렬성은 diffusion 고유 속성이 아니라 이산화 스케줄(한 스텝에 몇 토큰을 unmask하는가)에서 나온다. 병렬로 많이 뽑을수록 이산화 오차 ε_disc가 커져 slow-to-fast 스케줄이 필요하다. 실제로 가장 실용적인 쓰임은 diffusion LM을 AR의 speculative draft(DFlash 등)로 쓰는 것이다.
Q6. On-policy distillation이 표준 증류와 다른 점 두 가지를 쓰라.
① on-policy: 학생이 현재 정책으로 생성한 궤적에서 학습하므로 train–inference 분포 불일치가 감소. ② 토큰 단위 dense supervision을 유지(GRPO의 결과 보상과 대비).
