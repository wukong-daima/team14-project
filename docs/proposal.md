# 최신딥러닝이론및응용 강의 콘텐츠로 검증하는 자가 진화 LLM 하네스의 학습 효과: 오버피팅인가, 진짜 개선인가

**연세대학교 공학대학원 인공지능학과 · 최신딥러닝이론및응용 · 14조 (EvoLecture)**
제출일 2026-11-15 · 사이트 https://wukong-daima.github.io/team14-project/ · 저장소 https://github.com/wukong-daima/team14-project

## 1. 질문

모델 가중치를 바꾸지 않는 **자가 진화 하네스**가 학습 콘텐츠를 실제로 개선하는가? 개선분을 8주차에서 배운 대로 **오버피팅(O) · 테스트타임 스케일링(T) · 일반화(G)**로 분해하면 무엇이 남는가?

부질문: (a) 보상에서 출처 검증 항을 빼면(ablation) 루프의 행동이 어떻게 달라지는가(9주차 "부정확한 리워드"). (b) 수업에서 배운 기법이 Claude의 행동으로 관측되는가(테스트타임 스케일링, pass@k, 하네스 효과).

## 2. 배경과 동기

- 1주차: 정의된 문제를 푸는 AI에서 문제를 스스로 정의하는 에이전트로.
- 8주차: 하네스 최적화로 보고된 성능 향상의 상당 부분이 오버피팅과 호출 수 증가였다(ALFWorld 98%). Δ = E − B = O + T + G.
- 9주차: 리워드가 부정확하면 루프는 엉뚱한 방향으로 진화한다. pass@k로 망가진 문제를 찾는다.
- 우리는 이 경고를 **우리 자신의 학습 사이트**에서 재현·검증한다. 학습자(모델)는 그대로 두고 공부의 하네스만 바꾼다.

## 3. 실험 장치

| 구성 | 내용 | 상태 |

## 4. 측정

- **보상** `R = 0.6 · Acc_public + 0.4 · SourcePass`. `Acc_public`은 작은 모델(풀이자)이 사이트 본문만 보고 공개 세트를 푼 정답률, `SourcePass`는 콘텐츠 주장 중 출처 대조를 통과한 비율. 비공개 정답률은 보상에 쓰지 않는다.
- **분해** `Δ = Acc_after − Acc_before`, `O = Δ_public − Δ_heldout`, `T` = 호출 수 동일 설계라 0(호출 수 효과는 E1·E2로 별도), `G = Δ − O − T`.
- **신뢰구간** 문항 단위 부트스트랩 95%. 구간이 겹치면 "유의한 개선"이라 부르지 않는다.
- **채택 기준** 유출 검사 통과(패치가 문제 문장을 베끼지 않음) · HTML 정상 · R 상승. 채택돼도 사람이 PR을 검토한다.
- **행동 실험** E1 effort(low→xhigh) vs 정답률·비용, E2 pass@k vs pass^k(결함 문항 탐지), E3 자료 없음/브리프/페이지 조건 비교.

## 5. 사전 등록(결과 보기 전에 고정)

표본 목표 공개 150+, 비공개 50+, 라운드 3회 이상, 풀이 시드 3개 평균±표준편차. **예상: O가 Δ의 절반 이상일 가능성이 크다.** 그 경우 "수업이 경고한 현상을 재현했다"로 보고하며 결과를 숨기지 않는다. 결과가 "개선 없음"이어도 보고한다.

## 7. 한계와 정직성 규칙

- 풀이자는 사람이 아니라 모델이다. 정답률은 "콘텐츠가 풀이자에게 주는 정보량"의 대리 지표로만 해석한다. 가능하면 조원 3명이 비공개 20문항을 전/후로 풀어 보조 근거를 붙인다.
- 표본이 작다. 신뢰구간을 항상 함께 보고한다.
- 모델 비교는 공개 자료만 쓰고, 모르는 것은 "비공개"로 표기한다. 요약본과 원본이 다르면 정정 박스로 드러낸다.
- 강의 자료 원본은 공개 저장소에 올리지 않는다.
